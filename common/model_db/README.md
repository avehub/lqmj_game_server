## 3.0基础ORM关系


#main：
1.说明：
* `基础业务表` 一般是配置、重要记录等，不分表

2.命名规范：
* `基础业务名` 重要基础类，例如用户表、邮件表
* `Conf + 业务名` 配置类，例如vip配置
* `User + 业务名` 记录类，数据有效期较长，一般可以复用记录，例如vip记录
* `Records + 业务名` 重要日志类，数据有效期较短
* `Stats + 业务名` 统计类，例如游戏场数
* `Items + 业务名` 虚拟产品类，例如货币、皮肤、装扮、英雄、道具


#log：
1.说明：
* `一般日志` 记录较多，访问量一般比较少，分表记录

2.命名规范：
* `Records + 业务名` 一般日志类，数据有效期较短，例如流水记录


#extra：
1.说明：
* `常用日志` 记录较多，访问量也比较多，常和业务逻辑挂钩，分表记录

2.命名规范：
* `Records + 业务名` 常用日志类，数据有效期较短，例如活跃值记录
